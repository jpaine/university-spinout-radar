# University Spinout Radar

## gstack

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools directly.

If gstack skills aren't working, run `cd .claude/skills/gstack && ./setup` to rebuild the binary and re-register skills.

### Available skills

- `/office-hours` — describe what you're building, get structured guidance
- `/plan-ceo-review` — CEO/founder review of a feature idea or plan
- `/plan-eng-review` — eng manager review of a plan
- `/plan-design-review` — designer review of a plan
- `/design-consultation` — design consultation
- `/design-shotgun` — generate multiple design directions
- `/design-html` — finalize an HTML design
- `/review` — pre-landing PR review (security, bugs, correctness)
- `/ship` — ship workflow: detect + merge changes
- `/land-and-deploy` — land and deploy workflow
- `/canary` — post-deploy canary monitoring
- `/benchmark` — performance regression detection
- `/browse` — fast headless browser for QA and research
- `/connect-chrome` — launch real Chrome controlled by Claude
- `/qa` — systematically QA test a web app
- `/qa-only` — report-only QA testing
- `/design-review` — designer's eye QA: find visual issues
- `/setup-browser-cookies` — import cookies from your real browser
- `/setup-deploy` — configure deployment settings
- `/retro` — weekly engineering retrospective
- `/investigate` — systematic debugging with root cause analysis
- `/document-release` — post-ship documentation updates
- `/codex` — OpenAI Codex CLI wrapper
- `/cso` — Chief Security Officer mode (OWASP + STRIDE audits)
- `/autoplan` — auto-review pipeline
- `/careful` — safety guardrails for destructive operations
- `/freeze` — restrict file edits to a specific boundary
- `/guard` — full safety mode
- `/unfreeze` — clear the freeze boundary
- `/gstack-upgrade` — upgrade gstack to the latest version
- `/learn` — manage project learnings
